# Terminal ASCII Camera

Russian version | [English](README.md)

Легкий Python-скрипт, который выводит изображение с веб-камеры в терминал прямо в виде **цветного ASCII-арта**. Без GUI, без отдельного окна — только символы и ANSI-цвета внутри терминала.

![demo](screenshots/demo.png)

## Возможности

- **Цветной вывод** — 24-битный truecolor или палитра xterm-256.
- **Автоподгонка** — подстраивается под размер окна терминала и реагирует на изменение в реальном времени.
- **Правильные пропорции** — учитывается форма символа терминала, изображение не растянуто.
- **Зеркальное отражение** — по умолчанию изображение отражено по горизонтали (как в зеркале).
- **Корректное завершение** — камера освобождается по Ctrl+C, SIGTERM, SIGHUP.
- **Работает офлайн** — никаких внешних сервисов.

## Требования

- Linux (проверено на Ubuntu 24.04)
- Python 3.8+
- Рабочая веб-камера (/dev/video*)
- Современный терминал с поддержкой truecolor (GNOME Terminal, Konsole, Alacritty, kitty, wezterm, iTerm2, Windows Terminal)

## Установка

### 1. Системные пакеты

    sudo apt update
    sudo apt install -y python3-opencv python3-numpy

### 2. Клонирование репозитория

    git clone https://github.com/ZeNeX1586/terminal-ascii-camera.git
    cd terminal-ascii-camera

### 3. Запуск

    python3 ascii_cam.py

Если камера не на /dev/video0:

    python3 ascii_cam.py 2

## Использование

После запуска терминал переключается в альтернативный экран и начинает выводить изображение с камеры в виде цветного ASCII. Выход — Ctrl+C. После этого терминал возвращается в исходное состояние.

### Если камера занята

Если видишь "Cannot open /dev/video0", значит камеру держит другой процесс. Освободи ее:

    sudo fuser -k /dev/video0
    python3 ascii_cam.py

## Настройки

Все параметры — в начале файла ascii_cam.py:

| Параметр | По умолчанию | Описание |
|---|---|---|
| CHARS | " .:-=+*#%@" | Символы от самого темного к самому светлому. |
| CHAR_ASPECT | 2.0 | Отношение высоты символа к ширине. Меняй, если изображение растянуто (попробуй 1.8 - 2.2). |
| FPS_LIMIT | 30 | Целевой FPS. Понижай до 15 на слабом железе. |
| MIRROR | True | Отражать по горизонтали (режим селфи). |
| COLOR_MODE | "truecolor" | "truecolor" (24-бит) или "256" (палитра xterm-256). |

### Если цвета не отображаются

Возможно, терминал не поддерживает 24-битный цвет. Установи:

    COLOR_MODE = "256"

### Если изображение растянуто по вертикали

У тебя другой шрифт в терминале. Подстрой:

    CHAR_ASPECT = 2.2   # для более высокого шрифта
    CHAR_ASPECT = 1.8   # для более низкого шрифта

### Если грузится CPU

    FPS_LIMIT = 15

## Как это работает

1. Каждый кадр захватывается с камеры через OpenCV.
2. Кадр масштабируется под сетку символов с учетом формы символа.
3. Яркость каждой ячейки превращается в символ из CHARS.
4. Цвет каждой ячейки оборачивается в ANSI-escape.
5. Весь кадр выводится в stdout одним write() с escape-кодом "курсор в 0,0", поэтому терминал перерисовывает без мерцания.

## Производительность

На современном CPU (Intel i5, AMD Ryzen 5) скрипт держит 30 FPS при размере терминала ~200x50 без заметной нагрузки. На старом железе снижай FPS_LIMIT до 15.
